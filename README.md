# KimiLM

**KimiLM** is a desktop app for AI agents that run on your own computer: chat, projects, memory, skills, plugins
and connectors, planned runs, scheduled tasks, long-running tasks, pictures and sound, apps and games, with models
you download and run locally (CPU or GPU) and, if you choose, online models with your own keys.

- The app (Electron + React): [app/README.md](app/README.md) — how to run it in development and build the installer.
- The engine (Python): [engine/README.md](engine/README.md) — how it works, release by release.
- Running it on a rented GPU: [deploy/runpod/README.md](deploy/runpod/README.md).

KimiLM is also the desktop of [KimiOS](https://github.com/kiplabat/KimiOS), which installs the Linux build from
this repository's releases.

Looking for the Datavera command-line publishing agent that used to live here? It has its own repository:
[kiplabat/datavera-agent](https://github.com/kiplabat/datavera-agent).
